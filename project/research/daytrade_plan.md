# デイトレードの検証計画書（BTC・ETH）

最終更新：2026-11-28

1日の中で入って出る短い売買（デイトレード）を、これまでと同じ物差しで調べるための計画書。これまでの計画書（`plan.md`）で残った候補（S4案・R02）は、1日1回の操作で翌朝まで持つ形だった。ここでは、持つ時間が数十分〜十数時間で、スワップがつく朝6〜7時の前に決済する形を中心に101件を並べた。検証の進み具合と結果は「8. 一覧」に書き込む（第1回：2026-11-28、優先「高」の19件。第2回：2026-11-28、TA・TB・TC・TK・TL の「中」17件。第3回：2026-11-28、TD・TE・TG・TH・TJ の「中」13件）。

- 一覧の正本は `daytrade_plan.csv`。このファイルの「8. 一覧」は `python3 project/tools/plan_tool.py --plan daytrade md` で作る
- 検証の数字は `results.csv`（グループ「計画・デイトレ第N回」）、考察は `README.md` に残す

## 1. 目的

- 年単位で負けない。落ち込みが小さい。大勝ち頼みではなく、勝ちを重ねる（これまでと同じ）
- その日のうちに決済し、スワップを払わない
- 今の候補（S4案）と動きが違い、組み合わせると全体が安定する形を探す
- 実際に回せるかを、形ごとに見る（朝8時20分の予約注文だけで済むか、決まった時刻の操作が要るか、自動売買が要るか）

## 2. 出発点（これまでにわかっていること）

- 短い足（15分足・30分足・1時間足）の売買は、手数料で利益が消えやすい。15分足の多数決は年−15%ほどだった
- 時間帯・曜日の傾向は、前半と後半でくり返さない（B22・B03）
- 1時間・4時間の値幅ブレイクは、マイナスか後半が弱い（A28・第6回）
- 日中の逆張り（始値から下げたら買う）は年−13%前後
- アジア時間（日本9〜17時）の動きは、夜まで続きやすい（B04：手数料の前で年+11%ほど）
- 値幅ブレイクは翌朝まで持つ形が一番良く、早く決済するほど成績が下がる（K13、6・12・18時間の決済）

デイトレードでは、コストを超える利益があるかが一番の関門になる。

## 3. 共通の決まり

| 項目 | 内容 |
|---|---|
| データ | Binance の BTCUSDT・ETHUSDT の15分足（2017年8月〜、出来高・成行の買いつき）。足の中の順番の確認に5分足 |
| 期間 | 2018年1月〜2026年11月。前半（2018〜2022年）で設定を選び、後半（2023年〜）で確かめる |
| 取引する時間 | 日本時間9時〜翌5時。5時には必ず決済して、スワップを払わない（形によって変える時は書く） |
| コスト | Vantage CFD の往復0.05%（スプレッド）。往復0.10%（倍）と0%（コストなし）でも計算する |
| スワップ | 日本時間7時（夏時間は6時）をまたいだ買いだけ。金曜は3日分、土日はなし |
| 1回の量 | 日足のATR1本分の値動き＝資金の0.5%（これまでと同じ物差し）。安定度は量で変わらない |
| 向き | 買い＋売り（売りも×1）と、買いだけ。S1の向き（BTCの5日平均）で絞る形も見る |
| 約定 | 合図は足が終わってから見て、次の足の始値か逆指値で入る。損切りと利確が同じ足に入った時は、損切りを先とみなす。良さそうな形は5分足で確かめる |
| 見る数字 | これまでの数字に加えて、取引の回数、持つ時間、1回あたりの損益（値段の何%か）、コストの割合、勝率、コストを倍にした時の成績 |

## 4. 合格の基準

| 段階 | 条件 |
|---|---|
| 1次（ふるい） | コスト込みで年平均がプラス。前半・後半の両方でプラス。取引は年100回以上（2銘柄の合計） |
| 2次（頑丈さ） | 設定を変えた形の7割以上がプラス。BTC・ETHのどちらでもプラス。安定度0.8以上。負ける年は2年まで。往復0.10%（コストが倍）でもプラス |
| 3次（今の候補に足せるか） | S4案との月の損益の相関が0.5未満。S4案に×0.5で足すと、安定度がS4案（2.18）より上がる |
| 採用の候補 | 3次まで合格し、朝の予約注文・決まった時刻の操作・自動売買のどれかで続けられる |

## 5. 「たまたま良く見える」を防ぐ

- 前半で選び、後半で確かめる。設定を前後にずらす。段階で判定する（これまでと同じ）
- 同じ回数・同じ持ち時間でランダムに入った場合（TP01）と比べる
- 取引の回数が多いので、1回あたりの利益がコストの何倍あるかも見る。コストの2倍に届かない形は、スプレッドが少し広がるだけで消える
